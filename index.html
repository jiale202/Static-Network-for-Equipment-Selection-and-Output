④ 使用说明
选购流程：选产品 → 勾选选配装置、数量 → 加入清单 → 继续添加其它产品（自动连线排序）→ 需方信息 → 保存导出 Excel / 一键生成报价方案。
价格留空即显示「待定」，可事后在维护页或清单里直接填写。单价（万元）为含税价。
双端使用：手机 / 电脑浏览器均可打开本页面；数据按设备独立存储，用 JSON 导出导入即可同步。
